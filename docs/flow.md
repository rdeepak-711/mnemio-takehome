## Boundaries

- **Network:** only `src/ai/client.ts` talks to the outside world (OpenRouter). Tests replace it with a fake HTTP server.
- **"External" provider:** `src/mock/provider.ts` writes to `mock_outbox` on its own connection, outside the send transaction, so it behaves like a third-party API that has already happened when our transaction rolls back. That's what the crash test (T13) relies on.
- **Time:** only `src/clock.ts` decides what "now" is. `ai.llm_usage` is the single place that uses real time (OpenRouter counts real days).
- **No auth, no tenants.** Single local user. The dashboard (T21a) has no login either, so it is for a local machine only.
- **HTTP (dashboard):** the browser only talks to `app/api/**/route.ts`; route handlers parse the request and call `src/web/*`, and contain no SQL (D56). Errors become JSON: `BadRequest` → 400, `SimBusy` → 409, unknown contact → 404, anything else → 500.
